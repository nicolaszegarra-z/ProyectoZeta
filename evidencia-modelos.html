CONCEPCIÓN · 02

Evidencia y cambio de modelos

Una página separada para explicar cómo la evidencia puede apoyar, descartar o modificar modelos científicos.

01

La astronomía como historia de correcciones

A lo largo de estas etapas se repite una cadena: una idea previa se enfrenta a una pregunta; una herramienta permite obtener evidencia; la evidencia modifica el modelo y produce una nueva percepción.

IDEA PREVIA→PREGUNTA→HERRAMIENTA→EVIDENCIA→CAMBIO DE MODELO→NUEVA PERCEPCIÓN
Pensamiento crítico aquí no significa “ser escéptico de todo”. Significa distinguir observación de interpretación, comparar hipótesis y aceptar que una explicación puede ser reemplazada cuando la evidencia lo exige.
Método de lectura: observación → evidencia → revisión del modelo → nueva percepción.
02

Una estructura para evaluar explicaciones

Este apartado queda reservado exclusivamente para la relación entre observación, instrumentos, evidencia, hipótesis y cambio de modelos. La información definitiva se completará con la selección final de fuentes.
